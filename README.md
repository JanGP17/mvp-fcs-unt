# MVP de predesarrollo · Portal FCS UNT

Este repositorio contiene una **reconstrucción funcional del MVP de predesarrollo** del Portal Web de la Facultad de Ciencias Sociales de la Universidad Nacional de Trujillo.

## Objetivo académico

Servir como evidencia del planteamiento previo al desarrollo completo, mostrando la navegación y los módulos prioritarios definidos para la primera versión funcional.

El MVP incluye:

- portal público de Facultad;
- las cinco Escuelas Profesionales;
- Identidad y Recursos;
- Formación: currículas, horarios, docentes y documentos;
- Actualidad: noticias, eventos, oportunidades e investigación;
- Comunidad y egresados;
- buscador demostrativo;
- panel administrativo de Facultad/Escuela;
- flujo demostrativo de difusión.

Los datos son ficticios. El MVP no consulta ni modifica la base de datos productiva y no contiene información personal real.

> Nota de integridad académica: este recurso es una reconstrucción funcional posterior basada en los requerimientos iniciales del proyecto. No debe presentarse como una captura histórica tomada en una fecha anterior.
